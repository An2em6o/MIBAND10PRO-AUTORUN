# 使用
## 安装管理器
首先安装[release](https://github.com/An2em6o/MIBAND10PRO-AUTORUN/releases)界面中的`module.autorun.Manager.bin`文件，
其中：
`module.autorun.canopus.bin`是修改版的canopus，  
`module.autorun.chaos.bin`则是经过修改了的chaos（不推荐使用，最新版本可见[chaos官方仓库](https://github.com/WenHuaYiYang/Chaos-Module)里面的构建，或者从qq群1018886448获取到最新发布，  
`module.autorun.Manager.bin`这个是自启动管理器，它负责控制各个已接入到管理器自启动支持的native app的自启动管理，顾名思义就是控制哪些原生应用的启动用的。  
`module.autorun.shellpp-ii.bin`这个是Shell++ ii的特殊修改版本。

下载完成后，你可以使用第三方软件[oronbox](https://oronbox.zxor.org/)安装这些表盘文件。

# 使用
在安装manager表盘之后，点击自启动管理，然后点击两次安装按钮。这样才会被正确写入文件

然后将各个模块软件的安装器中点击自启动选项，写入文件

写入文件后在manager中会显示对应的模块。

确认无误后，返回主页，点击重建自启动，

然后点击开，即可食用。
